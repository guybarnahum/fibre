# relationships

Manages family, couples, sponsors, mentors, trust, fondness, resentment, and narrative relatives across humans, Threads, companies, institutions, and other durable entities.

Dignity appraisals may propose bounded fondness and resentment deltas toward a requesting entity. This service validates evidence, bounds, causation, repetition, and repair before appending relationship-attitude events. Fondness and resentment remain separate dimensions and may coexist.

This directory currently defines a service boundary only. Implementation must use portable domain contracts and must not allow LLM output to mutate protected state directly.
