# Bidding Behavior

## Hypothesis

Measure how genotype, reputation, reserves, confidence, and relationships affect price, scope, and subcontracting bids.

## Required protocol

- Version the model, prompt compiler, fixtures, and evaluator.
- Define control and treatment groups.
- State the expected observable difference before running.
- Preserve raw outputs separately from interpretation.
- Record costs and failed runs.
- Do not promote results into canonical design without an ADR.
