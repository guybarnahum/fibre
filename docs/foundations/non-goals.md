# Non-goals for the initial prototype

- Claiming that Threads are conscious or legally persons.
- Creating a cryptocurrency or externally tradable token.
- Perfectly simulating human biology, psychology, culture, or genetics.
- Building a universal governance system.
- Supporting unrestricted autonomous financial or legal actions.
- Storing private sponsor archives or credentials in the main Git repository.
- Selecting a permanent cloud provider or LLM framework before experiments justify it.
- Building every social institution before the world kernel and canonical scenarios work.
