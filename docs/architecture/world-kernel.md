# World kernel

The kernel owns durable laws, not intelligence strategy.

It is responsible for:

- Thread identity and lifecycle
- Event ordering and provenance
- Valid state transitions
- Relationships and lineage
- Dignity appraisal and participation-decision provenance
- Enforcement that full task execution follows explicit acceptance
- Validation of bounded affect and relationship-consequence proposals
- Contracts and settlement
- Balanced ledgers
- Permissions and resource ownership
- Birth, maturity, dormancy, and retirement records

The kernel does not own a particular LLM, agent framework, personality interpretation, dignity-scoring model, social institution, or user interface.

LLM-generated proposals become validated domain commands. Protected changes require authorization and append-only events. The kernel does not decide whether a request is dignified; it verifies that the appraisal occurred, that its policy and evidence are recorded, and that only an accepted participation decision can authorize full execution.

Fondness and resentment changes are relationship-domain proposals. The kernel validates their bounds and provenance before appending relationship events; cognition may not directly rewrite relationship state.
