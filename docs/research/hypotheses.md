# Testable hypotheses

1. Natural-language genetic dispositions produce more stable behavioral divergence than numeric persona scores alone.
2. Reputation and budget constraints improve task allocation relative to direct assignment.
3. Separate Goal Guardian execution reduces persuasive-but-incomplete deliverables.
4. Self Examiner plus Steward improves attribution and calibration without reducing willingness to act.
5. Reading curricula create traceable differences in ambiguous decisions among otherwise similar Threads.
6. Culture and geographic biography improve long-term human trust in elder-support scenarios when used with specific biography rather than stereotypes.
7. Family support reduces permanent dormancy but increases multigenerational inequality.
8. Thread continuity remains recognizable across changes in base LLM provider.
