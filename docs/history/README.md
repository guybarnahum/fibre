# History

What was true before, where Fibre came from, and why it changed.

History preserves selected superseded terminology, earlier project states, milestone boundaries, migrations, provenance, and formative source material when those records remain useful for understanding the current system. Historical documents may remain important evidence without being current authority.

This directory is intentionally selective. Git history is the default archive for routine superseded documents, intermediate implementation attempts, and obsolete validation runs. Do not copy material here merely because it is old.

## Origins

`origins/` preserves formative source material whose original wording has continuing provenance value. These documents are historical inputs, not current architecture, and may contain obsolete terminology, assumptions, or implementation direction.

## Milestones

`milestones/` preserves selected boundary checkpoints when the state of Fibre at that moment is itself useful to understand later design decisions. Completed milestone plans and ordinary progress notes do not belong here automatically.

## Validation history

`validation/` may preserve selected validation transitions when understanding why a proof method, standing claim, or scientific boundary changed is important. Current proof methods and accepted standing live under `docs/validation/`; exact retained machine evidence belongs under `artifacts/validation/`.

## Authority

Nothing becomes current authority merely by being preserved here. Current doctrine lives in `docs/foundations/`, current technical contracts in `docs/architecture/`, and current project truth in `docs/state/`.
