# Current priorities

2. Preserve the deterministic milestone boundary: no production LLM provider, marketplace, embodiment, family, high-availability, multi-region, or production cloud scope until the persistent round trip passes.
3. Convert the static Thread Editor into an API-backed inspection and simulation tool as part of M1, including access-aware views of private stance, authorization, disclosure strategy, and external expression.
4. Add event-backed authorization issuance and one-time consumption after the portable structural binding is stable.
5. Establish repeatable behavioral evaluation, targeted mutation analysis, and drift baselines throughout implementation; do not treat a passing test count as sufficient evidence.
6. After M1, implement Identity and Embodiment v0.
7. Execute the web-product-studio task-marketplace vertical slice after the Thread lifecycle and identity foundations are reliable.
