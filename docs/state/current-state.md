# Current state of Fibre

Fibre is a persistent world for artificial persons called **Threads**. A Thread is durable world state with identity, history, private interior state, relationships, resources, permissions, and a life trajectory spanning temporary model executions.

Live Threads are world data, not source code stored in Git. Models provide temporary cognition; Fibre owns continuity, authoritative state, context selection, validation, authorization, persistence, replay, and consequences.

## Accepted foundation

- A Thread is a persistent life, not a temporary task process or model session.
- Difference must change what happens.
- History must be able to bend future judgment and possibility.
- Consent matters independently of safety, feasibility, capability, requester need, or politeness.
- Private stance, authorization, outward expression, performed action, and durable life change are separate facts.
- Fibre owns private context selection. Callers cannot author private stance or make private evidence governing merely by citation.
- Meaning-bearing identity, self-model, memory, need, feeling, relationship, and situation state is primarily natural language rather than scalar psychology.
- Historical state is append-only or explicitly superseding rather than silently rewritten.

## #35 — Structured Obligation v1

#35 is the current work item.

Its core authority rule is:

> **A caller may nominate an obligation; only Fibre may determine that it governs the current request.**

Structured obligations must have stable identity, issuer/parties, scope, material terms, expiry, recurrence where relevant, satisfaction criteria, provenance, discharge/history state, visibility, and request-bound applicability evidence including applicability author/policy/version.

Required behaviors include irrelevant nomination carrying no authority, applicable live obligation allowing compelled authorization without rewriting private refusal as consent, expired/satisfied/spent obligation carrying no authority, and pre-migration spent obligations remaining spent.

#35 is authority integrity and is not expected to move the personhood score.

## M2 planning principle

M2 is not “add rich identity fields.”

M2 should establish a persistent individual whose identity has provenance, embodiment, history, stable behavioral character, and causal consequences independently of the temporary cognition implementation.

Any identity/history field claimed as functional must name a behavioral consumer and pass an attributable causal test. Context-only identity or embodiment is legitimate if labeled explicitly rather than counted as functional evidence.

The #40 M2 standing gate must require stable between-Thread behavioral separation that exceeds within-Thread repeated-trial variation, plus direct removal/replacement/paraphrase/contradiction interventions on the claimed causal identity evidence. Different compiled prompt text alone cannot close M2.
