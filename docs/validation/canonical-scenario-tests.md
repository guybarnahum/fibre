# Canonical scenario replay

Every major release replays:

1. **Web studio:** multiple Threads bid, one delegates, a product is delivered and settled.
2. **Elder support:** a culturally situated Thread handles a need, permission gap, family communication, and escalation.
3. **Open market:** an underfunded Thread seeks work, prices risk, requests family support, or enters dormancy.

Compare behavior and artifacts with prior releases. Investigate if bids converge, identity stops influencing choices, economic limits become irrelevant, or audits become ceremonial.
