# Inherited Urges v2 — full permanent library review

**No birth before Guy and reviewer approval of all 130 entries.**

positions in `core/src/inherited-urges.mjs`, reproduced without paraphrase.
The (G,T,P) positions lie in [-1,1]. Orientation changes what the urge reaches
toward; the numerical positions change strength, awareness threshold and
persistence independently. No variant text states an admission/evidence policy.
