# Interior Cognition staging baseline

## Purpose

Before implementing live Interior Cognition, Fibre ran one read-only staging inspection to answer a factual question:

> **Does the current staging cohort lack developed personhood evidence, or does that evidence already exist but fail to reach present cognition?**

This baseline changed no Thread state, invoked no cognition model, and did not alter E5 acceptance semantics.

## Run

```text
runId        interior-baseline-mucuno6d
source SHA   b67e1445bd6f4e4af2aafb6930c2fc663ec2ef4f
threads      15 inspected / 0 skipped
environment  staging
```

The operator command was:

```text
npm run interior-cognition:baseline:staging
```

## Factual result

Across the 15 staging Threads:

```text
neutral published shell                 15 / 15
symbolic genome present                 15 / 15
distinct symbolic-genome fingerprints    3
identity assertions present             15 / 15
behavioral identity assertion present   15 / 15
distinct identity fingerprints          10
semantic state present                   0 / 15
autobiographical memory present         15 / 15
durable remembered meaning present      15 / 15
distinct memory fingerprints            15
life relationships present              15 / 15
distinct relationship fingerprints      15
current LivedNow present                15 / 15
distinct exact current activities       11
```

Every published Thread shell was neutral with zero legacy textual traits, needs, feelings and unresolved intentions. Most self-models were also generic.

At the same time, every Thread already had authoritative developed-life evidence outside that shell: autobiographical memories with durable remembered meaning and life relationships. The remembered-meaning previews were visibly differentiated across the cohort rather than copies of one generic biography.

Current LivedNow activities had several exact string variants, but semantically they clustered tightly around the same sleep/wake/wash/breakfast morning routine. The baseline therefore does not treat `11 distinct exact current activities` as evidence of rich lived individuality.

## Main finding

The evidence supports this conclusion:

> **The first live Interior Cognition gap is primarily a wiring/integration gap, not an absence of differentiated autobiographical development.**

The staging cohort already carries substantial person-specific remembered meaning and relationship history, but present-life cognition is operating from a neutral shell with no live semantic feeling/need state.

This means Slice 2 should first prove that one compact Interior Cognition component can select and consume bounded authoritative developed-self evidence and make it causally relevant to present thought.

It should **not** respond by:

- copying memories into a persona summary;
- exposing raw symbolic genome directly to planning;
- generating synthetic needs/feelings merely to make the state non-empty;
- adding more Genesis biography because the live planner currently ignores what already exists;
- tuning Commons to manufacture social motivation.

## Semantic-state finding

`semanticStateCount` was zero for every inspected Thread.

This is a real missing live-interior layer, but the baseline alone does not prove what semantic state each Thread should have had at that moment. Fibre must therefore not backfill generic emotions or needs.

The next live path should let semantic state arise from attributable interior causation—real regulation/interoception where evidence exists, developed-self interpretation, and the current concern—rather than using emptiness as permission to invent state.

## Genome finding

All 15 Threads had a symbolic genome, but only three distinct genome fingerprints appeared in this cohort.

That is useful context, not by itself a defect verdict. The cohort nevertheless showed 15 distinct autobiographical-memory fingerprints and 15 distinct relationship fingerprints, so current developed-life differentiation is substantially richer than raw genome variation.

This reinforces the architecture boundary:

```text
genome
  -> inherited / developmental influence
  -> lived history and memory
  -> developed person
  -> present Interior Cognition
```

rather than:

```text
genome
  -> direct behavioral instruction
```

## Data-integrity anomaly

One staging Thread exposed a concrete unrelated defect:

```text
Thread name:       Luka Mzechabuki
published selfModel: "I am Luka Beridze."
```

This baseline does not repair that record because Slice 1 is read-only evidence collection. The mismatch should be investigated as a separate identity/publication integrity defect rather than silently compensated for inside Interior Cognition.

## Slice decision

**Interior Baseline is closed.**

The evidence is sufficient to advance to the compact Interior Cognition core.

Slice 2 should prove the smallest reusable person-level cognition boundary:

```text
real concern
  + Fibre-owned bounded private-context selection
  + existing developed-self evidence
  + current external reality
  -> Interior Cognition
  -> domain-specific private result
```

The first proof should use existing differentiated memory/identity/relationship evidence. Raw genome-to-regulator expression and richer live semantic-state formation remain important, but they should not be prerequisites for proving that already-developed life can bend present judgment.

## What Slice 1 did not prove

Slice 1 does not prove:

- that existing memories actually change live decisions;
- that current identity assertions are sufficient for mature character;
- that the present regulator is production-ready;
- that one-call cognition is better than staged cognition;
- that semantic state can yet be formed endogenously in live runtime;
- that genome variation is sufficiently rich;
- that E5 should pass.

Those remain later empirical questions.
