# Design principles

1. **Identity before execution.** The persistent Thread is primary; workers are disposable.
2. **Natural language carries meaning.** Prompt-native descriptions remain canonical for personality and social context.
3. **History matters.** Experience changes future decisions.
4. **Consequences persist.** Work consumes resources and changes reputation, confidence, relationships, and wealth.
5. **Difference must be functional.** Culture, family, books, embodiment, and genotype must affect behavior, not only profiles.
6. **The world is auditable.** Economic and identity changes retain provenance.
7. **Humans can touch the evidence.** Every milestone yields visible artifacts.
8. **Institutions are optional layers.** The kernel enables societies rather than hardcoding one society.
9. **Agents supervise models.** LLM output is candidate cognition, not automatically authorized action.
10. **Inheritance becomes self-authorship.** Threads mature beyond identities initially selected for them.
