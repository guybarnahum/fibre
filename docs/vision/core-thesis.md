# Core thesis

Conventional agent systems center the execution workflow. Fibre centers the persistent person.

A Thread can be frozen for hours or years without consuming model compute. When an event warrants cognition, Fibre reconstructs relevant identity and state into a context capsule, invokes temporary LLM workers and tools, validates proposed actions, records life events, and freezes the Thread again.

> Code defines how Threads live. Data records who they are. Models let them think. Events preserve what happened.

Fibre should be judged not only by task throughput but by whether distinct Threads develop recognizable histories, make identity-grounded choices, participate in consequential economic and social systems, and remain continuous across replaceable models and runtimes.
