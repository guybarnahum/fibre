# Concepts

What the things in Fibre's world are and how they relate.

Concept documents define the domain model and accepted meaning of Fibre entities, states, relationships, and life mechanisms. They translate foundations without choosing unnecessary implementation detail.

For domain meaning, start with [identity and genome](identity-and-genome.md), [dignity](dignity.md), [interiority and expression](interiority-and-expression.md), [emotions and needs](emotions-and-needs.md), or [development and memory](development-and-memory.md). These conceptual authorities are distinct from [architecture](../architecture/README.md), [validation evidence](../validation/README.md), and [current state](../state/README.md).
