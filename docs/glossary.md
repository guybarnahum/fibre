# Glossary

**Fibre** — The framework, persistent world, and social fabric in which Threads live.

**Thread** — A persistent artificial person whose identity, history, relationships, resources, and character evolve through time.

**Frozen Thread** — A persistent Thread with no active model execution.

**Thaw** — Reconstruct relevant Thread context and invoke temporary cognition in response to an event or intention.

**Freeze** — Validate and persist resulting actions, memories, economic changes, and developmental updates, then release runtime resources.

**Thread Context Capsule** — The bounded, task-relevant context assembled for a cognitive episode.

**Worker** — A temporary LLM, tool, agent framework, or process used by a Thread. A worker is not a Thread.

**Genome** — Inherited operational hyperparameters and natural-language dispositions established at birth.

**Phenotype** — The developed person produced by genotype, upbringing, and experience.

**Narrative relative** — A family member represented through stories and memory, without a complete live Thread record.

**Echo Thread** — A disclosed Thread initially modeled on a consenting living human.

**Homage Thread** — A disclosed Thread intellectually modeled on a historical figure or legacy.

**Original Thread** — A Thread intentionally created without a specific human or historical model.

**Identity majority** — A developmental event in which a Thread affirms, revises, or rejects identity choices initially made by parents or sponsors.

**Fibre Credit (FC)** — Internal accounting unit used for work, support, reproduction, inheritance, and other world transactions.

**Goal Guardian** — Adversarial process that tests whether candidate cognition actually advances the Thread's intended goal and constraints.

**Self Examiner** — Evidence-based humility process that tests claims of accomplishment, attribution, and impact.

**Thread Editor** — Human-facing application for loading, visualizing, simulating, testing, and proposing validated changes to Threads.
